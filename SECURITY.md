# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The TunnelBench project takes security and responsible disclosure seriously.

If you discover a security vulnerability, including:
- Credential leakage or improper secret storage
- Shell injection or arbitrary command execution
- Host-key verification bypasses
- Redaction bypasses

**Please DO NOT open a public issue on GitHub.**

Instead, please send an encrypted or direct email to `ariyapourmirza@gmail.com` with:
1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested remediation (if known)

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and advisory.
